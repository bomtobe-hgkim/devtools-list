# Contributing

Thanks for helping make the DevTools directory more comprehensive.

## Add or update a DevTool

1. Edit `data/devtools.json`.
2. Keep entries in the existing JSON object format: `slug`, `name`, `url`, and `description`.
3. Use the company’s canonical HTTPS homepage and a short, factual description.
4. Run `npm run generate` to update `README.md`.
5. Run `npm run check` and open a pull request.

You can also [open an issue](https://github.com/jackbridger/devtools-list/issues/new?template=add-a-devtool.yml) if you would rather suggest a tool without editing the list yourself.
